Understanding HSN & SAC Codes

What are HSN Codes?

HSN (Harmonized System of Nomenclature) is a globally standardized system to classify goods. Under GST, HSN codes determine the applicable tax rate. Codes come in 2, 4, 6, or 8 digits — more digits mean more specificity.

What are SAC Codes?

SAC (Services Accounting Code) classifies services under GST. All SAC codes are 6 digits starting with 99. For example, 998311 covers IT consulting and 997212 covers courier services.

Using on GST Invoices

Every GST invoice must include the HSN/SAC code for each line item. Incorrect codes can lead to GST return mismatches, ITC rejection, and notices from the tax department. Always verify your codes.

Frequently Asked Questions

HSN (Harmonized System of Nomenclature) is an internationally standardized system of names and numbers to classify traded goods. Under Indian GST, every taxable good is classified using an HSN code that determines the applicable GST rate. The system was developed by the World Customs Organization (WCO) and is used by over 200 countries.
SAC (Services Accounting Code) is used to classify services under GST. SAC codes are 6-digit codes starting with 99. Each SAC code has a corresponding GST rate. They are similar to HSN codes but specifically for services. For example, IT services fall under SAC 9983, while construction services use SAC 9954.
For businesses with annual turnover up to ₹5 crore: 4-digit HSN code is mandatory on invoices. For turnover above ₹5 crore: 6-digit HSN code is required. For exports and imports: 8-digit HSN codes are mandatory. Nil-rated and exempt supplies may use 2-digit chapter headings.
